# Leitura de fotos e estimativa de medidas

Uma foto não tem escala. Para estimar medidas, encontre objetos de tamanho conhecido **no mesmo plano** da peça a medir e faça proporção. Use pelo menos duas referências quando possível e informe a faixa (ex.: "altura 7'6"–8'2", estimada pela porta e pelo siding").

## Referências de escala comuns (EUA)

| Referência | Medida típica |
|---|---|
| Porta externa | 80" altura × 36" largura |
| Porta de garagem | 7' ou 8' altura; 8', 9' ou 16' largura |
| Janela de cozinha | peitoril ~36"–42" do piso interno |
| Lap siding (vinil/fibrocimento) | 4"–7" de exposição por fiada (conte as fiadas) |
| Tijolo | 2 5/8" altura + junta 3/8" ≈ 3" por fiada; 8" comprimento |
| Bloco de concreto | 8" × 16" |
| Poste 4x4 / 6x6 | 3.5" / 5.5" reais |
| Tábua 1x6 / 2x6 | 5.5" de largura real |
| Deck board composite | 5.5" de largura |
| Piquete de cerca | 5.5" (1x6) ou 3.5" (1x4) |
| Tomada / interruptor | placa ~4.5" altura; tomada ~12"–16" do piso |
| Degrau | espelho 7"–7.75", piso 10"–11" |
| Pessoa adulta | 5'4"–6'0" (referência fraca) |
| Mangueira / torneira externa | ~18"–24" do chão |

## Técnica

1. **Conte em vez de medir** quando der: número de postes, número de fiadas de ripas, número de caibros. Contagens são muito mais confiáveis que medidas.
2. **Use a medida declarada** (texto/PDF) como âncora e derive o resto por proporção (ex.: comprimento total 265" conhecido → largura do vão = (265 − postes × 5.5) / nº de vãos).
3. **Perspectiva**: objetos mais longe parecem menores. Compare só coisas à mesma distância da câmera, ou use fotos frontais.
4. **Ripas**: conte as fiadas num vão e divida a altura do painel pelo número de fiadas para achar largura + espaço; confira com larguras comerciais (3.5", 5.5", 7.25").
5. **Imagem conceito / renderização**: trate como intenção estética, não como projeto. Quantidades vindas de render (nº de postes, caibros) costumam ser decorativas; confirme com o texto.

## O que registrar

Para cada medida usada no orçamento, anote: valor, origem (declarado / estimado), referência de escala usada e incerteza. Isso vai para a seção "Premissas" do spec.
