# 07 — Glossário do frete nos EUA (o agente precisa dominar)

> Termo como é dito ao telefone → significado → observação de uso.

## Pessoas e empresas
| Termo | Significado |
|---|---|
| **Broker / brokerage** | Intermediário com autoridade de broker (MC próprio) que conecta shipper e carrier |
| **Carrier rep / carrier sales / load planner** | Funcionário do broker que cobre as cargas com transportadoras (nossa contraparte) |
| **AM (account manager) / customer rep** | Funcionário do broker que cuida do shipper; costuma decidir o "max buy" |
| **Shipper / consignee / receiver** | Quem envia / quem recebe a carga |
| **Carrier** | Transportadora (de 1 caminhão a milhares) |
| **Owner-operator (O/O)** | Motorista dono do caminhão |
| **Dispatcher / dispatch** | Quem planeja e negocia as cargas do carrier (in-house ou dispatch service) |
| **Freight agent** | Agente independente vinculado a uma brokerage (ex.: modelo Landstar) |

## Documentos e cadastro
| Termo | Significado |
|---|---|
| **MC number / DOT number** | Números de registro no FMCSA (autoridade e identificação) |
| **Rate con (rate confirmation)** | Contrato da carga: valor, datas, accessorials. Vale o que está escrito |
| **BOL (bill of lading)** | Conhecimento de embarque, assinado na coleta |
| **POD (proof of delivery)** | Comprovante de entrega (BOL assinado no destino) |
| **Carrier packet / setup** | Cadastro do carrier no broker: W-9, COI, autoridade, dados bancários |
| **COI** | Certificado de seguro (auto liability, cargo) |
| **NOA (notice of assignment)** | Aviso de que o pagamento vai para a factoring |
| **Factoring** | Empresa que antecipa o recebimento das faturas |
| **Highway / MyCarrierPackets / RMIS / Carrier Assure** | Plataformas de cadastro e verificação de carriers |
| **DNU (do not use)** | Lista negra de carriers ou brokers |

## Preço e pagamento
| Termo | Significado |
|---|---|
| **All in** | Valor total, combustível incluído |
| **Linehaul** | Valor do frete sem combustível |
| **FSC (fuel surcharge)** | Adicional de combustível |
| **RPM (rate per mile)** | Valor por milha ("three-ten a mile") |
| **Posted rate** | Valor anunciado no load board (ponto de partida) |
| **Max buy** | Teto que o carrier rep pode pagar sem aprovação |
| **Spot / contract** | Frete avulso / frete com tabela contratada |
| **Quick pay** | Pagamento antecipado (geralmente com taxa de 1–5%) |
| **Net 30** | Pagamento em 30 dias |
| **Days-to-pay** | Média de dias que o broker leva para pagar |

## Accessorials (cobranças adicionais)
| Termo | Significado |
|---|---|
| **Detention** | Espera além das horas livres (geralmente 2 h) na coleta ou entrega; cobrada por hora |
| **Layover** | Motorista retido de um dia para o outro; cobrado por dia |
| **TONU (truck ordered not used)** | Caminhão foi até o local e a carga foi cancelada |
| **Lumper** | Taxa de descarga paga a terceiros no recebedor (reembolsável com recibo) |
| **Driver assist / touch** | Motorista ajuda a carregar ou descarregar |
| **Stop-off / extra stop** | Parada adicional |
| **Tarp fee** | Lona em carga de flatbed |
| **Pallet exchange** | Troca de pallets na entrega |

## Operação
| Termo | Significado |
|---|---|
| **Deadhead (DH-O / DH-D)** | Milhas vazias até a origem / após o destino |
| **Loaded miles** | Milhas carregadas |
| **Live load / live unload** | Motorista espera carregar ou descarregar |
| **Drop & hook / drop trailer** | Deixa uma carreta e pega outra (sem espera) |
| **Appointment (appt) / FCFS** | Horário marcado / ordem de chegada |
| **Reload / backhaul / headhaul** | Carga de volta / carga de retorno / perna principal |
| **Partial / LTL / FTL (TL)** | Carga parcial / fracionada / caminhão cheio |
| **Team** | Dois motoristas revezando (cargas expressas) |
| **HOS (hours of service)** | Limite de horas de direção; "full clock", "34-hour reset" |
| **ELD** | Dispositivo eletrônico que registra o HOS |
| **Check call** | Ligação de status durante o transporte |
| **Tracking** | Rastreamento via Macropoint, Trucker Tools, FourKites, Project44 |
| **ETA** | Previsão de chegada |
| **Fall-off** | Carrier fechou a carga e não apareceu (pecado capital) |
| **Covered** | Carga já tem caminhão |
| **OS&D** | Over, short & damaged: avarias e divergências |
| **Seal / seal number** | Lacre da carreta |
| **Scale ticket** | Comprovante de pesagem |
| **Blind shipment** | Shipper e consignee não sabem um do outro |

## Equipamentos
| Termo | Significado |
|---|---|
| **53' dry van** | Baú seco de 53 pés (o mais comum) |
| **Reefer** | Baú refrigerado; "continuous vs cycle", "pulp temp" |
| **Flatbed / step deck / RGN / conestoga** | Prancha / prancha rebaixada / removable gooseneck / prancha com lona deslizante |
| **Power only** | Só o cavalo (puxa a carreta do shipper) |
| **Box truck / straight truck** | Caminhão baú de 24–26 pés |
| **Hotshot** | Pickup pesada com prancha (cargas menores e urgentes) |
| **Sprinter / cargo van** | Van pequena |
| **Air ride, swing / roll doors, e-track, load locks, straps, chains, coil racks** | Especificações de carreta e amarração |

## Fraude
| Termo | Significado |
|---|---|
| **Double brokering** | Carrier (ou falso carrier) repassa a carga sem autorização |
| **Hostage load** | Carrier retém a carga para extorquir mais dinheiro |
| **Identity theft / MC hijack** | Golpista se passa por empresa legítima |
| **Fictitious pickup** | Retirada fraudulenta de carga |

## Frases típicas do broker (e o que significam)
| Frase | Tradução prática |
|---|---|
| "Where you at?" / "Where's your truck?" | Onde o caminhão está vazio e quando |
| "What do you need on it?" | Quanto você quer? |
| "I'm at 1,800 all in." | Minha oferta é 1.800 com tudo |
| "Can you do it for two flat?" | Faz por 2.000 redondos? |
| "Are you set up with us?" | Você já tem cadastro conosco? |
| "Shoot me your MC." | Me passe seu MC |
| "I'll send the rate con." | Fechado, vou mandar o contrato |
| "Let me run it by my AM." | Vou pedir aprovação para pagar mais |
| "It's covered." | Já tem caminhão |
| "What's your best?" | Me dê seu menor valor |
